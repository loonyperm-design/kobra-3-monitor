# Anycubic Kobra 3 — Нативный Android LAN Monitor & Control (.apk проект)

Готовый проект нативного Android-приложения (Kotlin + WebView UI) для мониторинга и полноценного управления 3D-принтером **Anycubic Kobra 3 / Kobra 3 Combo / V2 / Max (modelId: 20024 / 20027 / 20026)** по локальной Wi-Fi сети без облака Anycubic Cloud.

## Возможности управления
- **Печать:** Пауза (`pause`), Продолжить (`resume`), Стоп (`stop` с защитой от случайного нажатия), переключение скорости `Silent / Standard / Sport (до 600 мм/с)`.
- **Температуры и обдув:** Задавай температуру сопла (`0–300°C`) и стола PEI (`0–110°C`), пресеты `PLA / PETG / ABS / TPU`, ползунки кулеров и кнопка LED-подсветки.
- **Многоцветный бокс ACE Pro:** Выбор и подача прутка по клику на слоты `#1–#4`, управление активной сушкой (`45°C / 50°C / 55°C`, таймер `4ч / 8ч / 12ч`) и тумблер `Auto-Feed`.
- **Оси и автоуровень:** Парковка `G28 (XY / Все)`, ручной сдвиг по осям `X / Y / Z` с выбором шага (`0.1 / 1 / 10 / 50 мм`) и запуск калибровки `LeviQ 3.0 (7×7)`.
